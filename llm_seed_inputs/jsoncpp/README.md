# jsoncpp — LLM-pregenerated initial inputs (placeholder)

Drop LLM-generated **JSON** inputs here, one valid JSON document per file with
extension `.json`. They seed `elfuzz direct jsoncpp`'s initial population (copied
verbatim). Filenames are provenance only. `README.md` / dotfiles are ignored.

Until at least one `.json` file is added, `elfuzz direct jsoncpp` errors out.
See [../README.md](../README.md).
