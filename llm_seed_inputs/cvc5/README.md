# cvc5 — LLM-pregenerated initial inputs (placeholder)

Drop LLM-generated **SMT-LIB v2** inputs here, one valid SMT-LIB v2 script per
file with extension `.smt2`. They seed `elfuzz direct cvc5`'s initial population
(copied verbatim). Filenames are provenance only. `README.md` / dotfiles are
ignored.

Until at least one `.smt2` file is added, `elfuzz direct cvc5` errors out.
See [../README.md](../README.md).
