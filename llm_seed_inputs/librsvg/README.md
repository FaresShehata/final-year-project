# librsvg — LLM-pregenerated initial inputs (placeholder)

Drop LLM-generated **SVG** inputs here, one valid SVG document per file with
extension `.svg`. They seed `elfuzz direct librsvg`'s initial population (copied
verbatim). Filenames are provenance only. `README.md` / dotfiles are ignored.

Until at least one `.svg` file is added, `elfuzz direct librsvg` errors out.
See [../README.md](../README.md).
